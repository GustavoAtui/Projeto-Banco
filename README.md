# Banco em Python

Este é um sistema bancário simples desenvolvido em Python, permitindo o gerenciamento de contas, transações financeiras e funcionalidades adicionais como poupança. O sistema inclui funções para cadastro de clientes, operações bancárias, e extrato de transações.

## Funcionalidades

### 1. **Cadastro de Cliente**
Permite adicionar novos clientes ao banco, com informações como nome, CPF, e dados bancários.

### 2. **Apagar Cliente**
Permite a exclusão de clientes registrados no banco, removendo suas informações e contas associadas.

### 3. **Lista de Clientes**
Exibe uma lista de todos os clientes cadastrados no banco.

### 4. **Depósito**
Permite o depósito de valores na conta de um cliente. O saldo da conta é atualizado de acordo com o valor depositado.

### 5. **Débito**
Permite o débito de valores da conta de um cliente, com verificações de saldo suficiente.

### 6. **Extrato de Cliente**
Exibe um extrato detalhado das transações de um cliente específico, incluindo depósitos, débitos e a data/hora de cada transação.

### 7. **Transferência entre Contas**
Permite a transferência de valores entre duas contas de clientes diferentes, com controle de saldo e histórico de transações.

### 8. **Poupança**
Implementa uma função de poupança, permitindo que o cliente deposite um valor para gerar rendimentos periódicos.
